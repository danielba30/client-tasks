# ניהול משימות מול לקוח

Next.js 16 + Supabase, RTL עברית.

## הקמה
1. צור פרויקט ב-Supabase והרץ את `supabase/schema.sql` ב-SQL editor.
2. ב-Authentication → Users צור משתמש (מייל + סיסמה), והוסף לו שורה ב-`profiles` עם `role='elad'` (ההוראות בסוף הקובץ schema.sql).
3. `copy .env.local.example .env.local` ומלא את שלושת המפתחות.
4. `npm run dev` והתחבר. משם: הגדרות → אתרים ומשתמשים.

## הרשאות
- **אלעד**: רואה הכל, עורך כל שדה, מנהל אתרים ומשתמשים (מסך הגדרות), מוחק משימות.
- **לקוח**: רואה רק את המשימות שלו, יוצר משימות, מתכתב, ויכול לאשר משימה ("ממתין לאישור" ← "מאושר, ממתין") או להחזיר אחרי בדיקות ל"בעבודה". שעות וחיוב לקריאה בלבד.

כל גישת הנתונים עוברת בשרת (service role); ב-RLS אין policies כך שמפתח ה-anon לא חושף כלום.
